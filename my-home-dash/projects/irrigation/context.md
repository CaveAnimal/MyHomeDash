# Irrigation Project Context

## Current Working Design
- The irrigation system is meant to be partially removable.
- Most of the long-run plumbing will be built from old hoses cut to fit the layout.
- Those same old hoses may also act as protective sleeves over wiring where that is practical.
- The hose-based path is intended to stay in place over winter.
- The sprinkler heads and switches are intended to be removed seasonally.

## Current Assumptions
- Old hoses are available or expected to be available for reuse.
- The first prototype only needs one working controller path, one wired switch, and one tested head.
- Each switch will require its own wiring check before activation.
- Each sprinkler head must be tested individually before it can be accepted.

## What I Have Or Expect To Reuse
- Old hose stock for the base routing.
- The basic site layout concept for leaving the hose path in place through winter.
- A weekend-first work plan for getting the first unit running quickly.

## What I Need To Confirm Or Acquire
- Orbit B-hyve 12-station controller, model 57950.
- The final count and type of removable sprinkler heads.
- The final count and type of removable switches.
- Wire, waterproof connectors, and any controller-side termination materials.
- Any adapters, clamps, or fittings needed to connect hose-based runs to the controller and heads.
